# Super Φιλόλογος — Super-Philos

Εκπαιδευτικό παιχνίδι πλατφόρμας για τη μορφολογική εξάσκηση στα αρχαία ελληνικά ρήματα **εἰμί** και **λύω**, με ξεχωριστή συμπληρωματική ενότητα για το **γίγνομαι**.

**Έκδοση:** v3.0 (22 Νοεμβρίου 2026)

## Παίξε στον φυλλομετρητή

Μετά την ενεργοποίηση του GitHub Pages: **https://itzortzak.github.io/Super-Philos/**

Το παιχνίδι είναι ένα αυτόνομο `index.html` και λειτουργεί επίσης τοπικά, χωρίς εγκατάσταση. Άνοιξε το `index.html` με Chrome, Edge ή Firefox.

## Περιεχόμενο

- 956 μορφολογικές εγγραφές: 113 εἰμί, 697 λύω, 146 συμπληρωματικοί τύποι του γίγνομαι.
- Προσωπικοί τύποι, απαρέμφατα, μετοχές και πτώσεις σε ενικό και πληθυντικό. **Χωρίς δυϊκό**.
- Θεματικές πίστες, προσαρμοσμένα φίλτρα και βασικό, μεσαίο, προχωρημένο επίπεδο.
- **«ΟΛΟΙ οι τύποι»**: μία ερώτηση ανά μορφολογική εγγραφή, τερματισμός μετά την πλήρη κάλυψη.
- Πίστες πλατφόρμας, βαθμολογία, χρόνος και αναλυτικός έλεγχος απαντήσεων.
- Τοπική αποθήκευση της προόδου της πλήρους διαδρομής και δυνατότητα συνέχισης.
- Προβολή πινάκων κλίσης και εξαγωγή αποτελεσμάτων σε CSV.

## Οδηγίες

Κίνηση: **← / →** ή **A / D**. Άλμα: **διάστημα**, **↑** ή **W**. Απαντήσεις: **1–4** ή κλικ. Παύση: **P**. 

Για μικρότερη διάρκεια επέλεξε 12, 16, 24 ή 32 ερωτήσεις αντί της πλήρους διαδρομής.

## Δομή αποθετηρίου

- `index.html` — πλήρες παιχνίδι, αυτόνομο, χωρίς εξωτερικές εξαρτήσεις.
- `morphology_audit.csv` — αναλυτικός κατάλογος των τύπων και των γραμματικών χαρακτηριστικών τους.
- `PHILOLOGICAL_AUDIT.md` — έκθεση ελέγχου, πηγές και περιορισμοί.
- `RELEASE_NOTES.md` — αλλαγές έκδοσης.
- `.github/workflows/pages.yml` — αυτοματοποιημένη δημοσίευση GitHub Pages.

## Φιλολογική σημείωση

Οι τύποι ἐγενόμην, γέγονα και ἐγεγόνειν καταχωρίζονται **στο γίγνομαι**, όχι ως μορφές του εἰμί. Οι σπάνιοι περιφραστικοί τύποι αποτελούν γραμματικά υποδείγματα και δεν συνεπάγονται κατ’ ανάγκην ανεξάρτητη μαρτυρία κάθε μορφής σε σωζόμενο κείμενο.

Βασική γραμματική: H. W. Smyth, *Greek Grammar* (rev. G. M. Messing, 1956), §§383, 768. Επιπλέον τεκμηρίωση στο `PHILOLOGICAL_AUDIT.md`.

## Δημοσίευση

Το GitHub Actions workflow ανεβάζει την ιστοσελίδα στο GitHub Pages με κάθε νέα αλλαγή στον κύριο κλάδο `main`. Αν δεν ενεργοποιηθεί αυτόματα, στο αποθετήριο επιλέγουμε **Settings → Pages → Build and deployment → Source: GitHub Actions**.
