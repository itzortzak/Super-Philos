# Super Φιλόλογος — v3.3

Διαδραστικό παιχνίδι πλατφόρμας για την αρχαία ελληνική μορφολογία: **εἰμί**, **λύω** και χωριστά συμπληρωματικά συστήματα του **γίγνομαι**.

## Εκτέλεση

Ανοίξτε το `index.html` σε Chrome, Edge ή Firefox. Δεν χρειάζεται εγκατάσταση ή λογαριασμός. Η ιστοσελίδα λειτουργεί και χωρίς σύνδεση. Στο GitHub Pages: https://itzortzak.github.io/Super-Philos/

**Χειρισμός:** ←/→ ή A/D για μετακίνηση, διάστημα/↑/W για άλμα, 1–4 ή κλικ για τις απαντήσεις και P για παύση.

## Νέα χαρακτηριστικά v3.3

- **Πιο αραιά εμπόδια:** τα διαστήματα ανάμεσα στις πύλες αυξήθηκαν από 530 σε 820 μονάδες πίστας. Οι επίγειοι αντίπαλοι εμφανίζονται κατά κανόνα ένας ανά τέτοιο διάστημα στο κανονικό επίπεδο. Στο ήπιο εμφανίζονται αραιότερα, ενώ στα διακλαδισμένα τμήματα υπάρχουν επιπλέον εχθροί στην επάνω διαδρομή.
- **Ιπτάμενοι αντίπαλοι** που ανεβαίνουν σημαντικά ψηλότερα και κατεβαίνουν κοντά στο έδαφος. Οι κινήσεις τους επιτρέπουν, ανάλογα με τον χρόνο του άλματος, πέρασμα από κάτω ή από πάνω.
- **Μεγαλύτερη οριζόντια κίνηση** σε σκαθάρια, βράχους και ιπτάμενους αντιπάλους.
- **Δεύτερη, υπερυψωμένη διαδρομή** σε ορισμένα τμήματα. Οι πλατφόρμες είναι πραγματικά βατές: ο παίκτης πηδά επάνω τους και προσγειώνεται. Όταν υπάρχει διακλάδωση, μπορεί να συνεχίσει από ψηλά ή να παραμείνει στο κάτω επίπεδο, όπου συναντά διαφορετικά εμπόδια.
- **Πύλες σε υπερυψωμένες πλατφόρμες** (γαλάζιο χρώμα, ένδειξη «↑ ΠΗΔΗΞΕ»). Η πύλη ενεργοποιείται μόνο αν ο παίκτης πλησιάσει στο απαιτούμενο ύψος. Δεν παρακάμπτεται με τρέξιμο από κάτω.
- **Πραγματικά κενά στο έδαφος**, τα οποία απαιτούν άλμα ή, όπου υπάρχει, μετακίνηση από επάνω πλατφόρμα. Όταν ο παίκτης πέσει, χάνει μία καρδιά και επανέρχεται σε ασφαλές σημείο πριν από το εμπόδιο.
- **Προοδευτική εμφάνιση μηχανισμών:** η αρχή παραμένει ομαλή, με περισσότερα χάσματα και υπερυψωμένες πύλες από τη συνέχεια της διαδρομής.

## Διατηρούνται από τη v3.2

Η **μορφολογική βάση είναι αμετάβλητη: 956 εγγραφές** (113 εἰμί, 697 λύω, 146 γίγνομαι). Δεν περιλαμβάνεται δυϊκός αριθμός. Ορισμένες παραλλαγές και περιφραστικοί τύποι εμφανίζονται μόνο σε προχωρημένο επίπεδο. Οι τύποι του γίγνομαι παρουσιάζονται χωριστά, δεν είναι μορφολογικοί χρόνοι του εἰμί.

Οι ερωτήσεις διατηρούν **αύξουσα παιδαγωγική δυσκολία** από τις πρώτες προς τις τελευταίες πύλες, με τυχαία σειρά μέσα στις επιμέρους υποβαθμίδες. Στη λειτουργία **«ΟΛΟΙ οι τύποι»** κάθε επιλεγμένη εγγραφή εμφανίζεται μία φορά· οι σύντομες πίστες 12/16/24/32 ερωτήσεων λαμβάνουν τυχαίο δείγμα.

Διατηρούνται τα έξι τοπία, η βαθμολογία, οι χωριστοί χρόνοι παιχνιδιού/ερωτήσεων, ο πίνακας κλίσης και η εξαγωγή CSV. Στη μεγάλη διαδρομή η πρόοδος και η σειρά ερωτήσεων αποθηκεύονται τοπικά, εφόσον το επιτρέπει ο φυλλομετρητής.

## Έλεγχος και τεκμηρίωση

Τα αρχεία `tests/smoke.mjs` και `tests/physics.mjs` επαληθεύουν τον αριθμό των μορφολογικών εγγραφών, τις ερωτήσεις, τη γεωμετρία των εμποδίων και τη δυνατότητα άλματος. Το `PHILOLOGICAL_AUDIT.md` τεκμηριώνει τη φιλολογική βάση. Η v3.3 αποτελεί αλλαγή **στη φυσική του παιχνιδιού** και **όχι νέα φιλολογική αναθεώρηση**.
