# Super Φιλόλογος (Super-Philos)

Διαδραστικό παιχνίδι πλατφόρμας για τη μορφολογία των αρχαίων ελληνικών ρημάτων **εἰμί** και **λύω**, με ξεχωριστή συμπληρωματική ενότητα **γίγνομαι**.

**Τρέχουσα έκδοση:** **v3.1.1** (22 Νοεμβρίου 2026)

## Παίξε online

**[Εκκίνηση παιχνιδιού – GitHub Pages](https://itzortzak.github.io/Super-Philos/)**

Εναλλακτικά, κατέβασε το `index.html` ή το ZIP από την [τελευταία έκδοση (Releases)](https://github.com/itzortzak/Super-Philos/releases/latest) και άνοιξε το HTML στον υπολογιστή. Δεν χρειάζεται εγκατάσταση ή εξωτερική βιβλιοθήκη.

## Τι περιλαμβάνει

- **956 μορφολογικές εγγραφές**: 113 για το εἰμί, 697 για το λύω και 146 συμπληρωματικές για το γίγνομαι.
- Προσωπικούς τύπους, απαρέμφατα και μετοχές σε ενικό και πληθυντικό, με γένη και πτώσεις· χωρίς δυϊκό.
- Φίλτρα ανά ρήμα, χρόνο, έγκλιση, φωνή, πρόσωπο, αριθμό, είδος άσκησης και μορφολογικά χαρακτηριστικά μετοχής.
- Τρία επίπεδα δυσκολίας. Οι σπάνιοι και περιφραστικοί τύποι διατίθενται στο προχωρημένο.
- **Τυχαία σειρά** ερωτήσεων σε κάθε νέα παρτίδα. Στη λειτουργία **«ΟΛΟΙ οι τύποι»** εμφανίζεται κάθε επιλεγμένη μορφολογική εγγραφή μία φορά σε τυχαία σειρά· οι σύντομες παρτίδες 12–32 ερωτήσεων χρησιμοποιούν μεταβαλλόμενο δείγμα.
- **Έξι τοπία** (εναλλαγή κάθε τέσσερις πύλες) και **έξι διαφορετικούς εχθρούς**.
- Δύο χρονόμετρα, βαθμολογία, τελική αναφορά απαντήσεων και εξαγωγή CSV.
- Τοπική αποθήκευση και συνέχεια της πλήρους διαδρομής, με διατήρηση της σειράς ερωτήσεων.
- Ενσωματωμένους πίνακες κλίσης και εξαγωγή πλήρους καταλόγου.

## Μορφολογικές διευκρινίσεις

Τα **ἐγενόμην**, **γέγονα** και **ἐγεγόνειν** ανήκουν μορφολογικά στο **γίγνομαι** και εμφανίζονται χωριστά, όχι ως τύποι του εἰμί. Οι ενσωματωμένοι τύποι είναι διδακτικά κλιτικά παραδείγματα· η παρουσία περιφραστικού τύπου στη βάση δεν τεκμηριώνει αυτομάτως εμφάνισή του σε σωζόμενο αρχαίο κείμενο. Αναλυτικά στο [PHILOLOGICAL_AUDIT.md](PHILOLOGICAL_AUDIT.md).

## Δημοσίευση και εκδόσεις

Το GitHub Pages χρησιμοποιεί τον κλάδο **main**, κατάλογο **/(root)**. Η υπηρεσία GitHub Pages δημοσιεύει τις αλλαγές που γίνονται στο `main`.

Το workflow [pages.yml](.github/workflows/pages.yml) ελέγχει τη στατική εφαρμογή, δημιουργεί το πακέτο ZIP και εκδίδει το tag/release **v3.1.1** στο GitHub. Η έκδοση δηλώνεται επίσης στο [VERSION](VERSION). Η δημοσίευση Pages από τον κλάδο είναι ανεξάρτητη από τη δημιουργία release.
