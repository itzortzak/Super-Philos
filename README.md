# Super Φιλόλογος (Super-Philos)

Διαδραστικό εκπαιδευτικό παιχνίδι πλατφόρμας για τη μορφολογία των αρχαίων ελληνικών ρημάτων **εἰμί** και **λύω**, με χωριστή συμπληρωματική ενότητα **γίγνομαι**.

**Τρέχουσα έκδοση:** **v3.2** · 22 Νοεμβρίου 2026

## Παίξε online

**[Εκκίνηση παιχνιδιού – GitHub Pages](https://itzortzak.github.io/Super-Philos/)**

Για χρήση χωρίς σύνδεση, κατέβασε το `index.html` ή το ZIP από το [τελευταίο Release](https://github.com/itzortzak/Super-Philos/releases/latest) και άνοιξε το HTML στον φυλλομετρητή σου.

## Κύριες δυνατότητες

- **956 μορφολογικές εγγραφές:** 113 του εἰμί, 697 του λύω και 146 συμπληρωματικές του γίγνομαι.
- Προσωπικοί τύποι, απαρέμφατα, μετοχές με γένη και πτώσεις, μόνο σε ενικό και πληθυντικό.
- Φίλτρα ρήματος, χρόνου, φωνής, έγκλισης, αριθμού, προσώπου και χαρακτηριστικών μετοχής.
- **Προοδευτική δυσκολία:** οι πρώτες πύλες παρουσιάζουν βασικούς τύπους· οι επόμενες μεσαίους και προχωρημένους. Εφαρμόζεται πρόσθετη υποδιαβάθμιση εντός κάθε βαθμίδας.
- **Τυχαία σειρά μέσα σε κάθε υποβαθμίδα** σε κάθε νέα παρτίδα, χωρίς να παραβιάζεται η προοδευτική δυσκολία.
- Στις σύντομες πίστες 12, 16, 24 ή 32 ερωτήσεων, νέα **στρωματοποιημένη τυχαία επιλογή** κάθε φορά. Αν οι διαθέσιμοι τύποι περιορίζονται από τα φίλτρα, χρησιμοποιούνται μόνο οι συμβατές εγγραφές.
- Στη λειτουργία **«ΟΛΟΙ οι τύποι»** εξετάζεται μία φορά κάθε επιλεγμένη μορφολογική εγγραφή. Οι ομόγραφοι τύποι με διαφορετική γραμματική ανάλυση αποτελούν διακριτές εγγραφές.
- **Έξι εναλλασσόμενα τοπία** ανά τέσσερις πύλες και **έξι είδη εχθρών** με διαφορετική κίνηση.
- Χρονόμετρα πίστας και ερωτήσεων, βαθμολογία, αναλυτικές απαντήσεις, εξαγωγή CSV και πίνακες κλίσης.
- Τοπική αποθήκευση προόδου στην πλήρη διαδρομή, με διατήρηση της αρχικής σειράς ερωτήσεων.

## Παιδαγωγική διαβάθμιση

Το πεδίο «Γραμματική δυσκολία» ορίζει το **ανώτατο επιτρεπόμενο** επίπεδο. Στην πλήρη διαδρομή όλα τα διαθέσιμα ερωτήματα εμφανίζονται σε μη φθίνουσα σειρά δυσκολίας. Σε σύντομες πίστες, όταν είναι διαθέσιμες και οι τρεις βαθμίδες, εφαρμόζεται κατά προσέγγιση η κατανομή 40% βασικών, 35% μεσαίων και 25% προχωρημένων. Η ταξινόμηση είναι διδακτική και όχι στατιστική αποτίμηση συχνότητας.

## Μορφολογικές διευκρινίσεις

Τα **ἐγενόμην**, **γέγονα** και **ἐγεγόνειν** ανήκουν μορφολογικά στο **γίγνομαι** και περιλαμβάνονται σε χωριστή διδακτική ενότητα, όχι στην κλίση του εἰμί. Τα κλιτικά παραδείγματα, ιδίως οι περιφραστικοί σχηματισμοί, δεν πιστοποιούν από μόνα τους ιστορική εμφάνιση κάθε τύπου σε αρχαίο κείμενο. Βλ. [αναλυτικό φιλολογικό έλεγχο](PHILOLOGICAL_AUDIT.md).

## Έλεγχοι, δημοσίευση, εκδόσεις

Το έργο είναι **αυτόνομη στατική ιστοσελίδα** (`index.html` με ενσωματωμένα CSS και JavaScript). Η δημοσίευση γίνεται από τον κλάδο **main**, κατάλογο **/(root)**, μέσω GitHub Pages. Το [workflow](.github/workflows/pages.yml) ελέγχει τη μορφολογική βάση και τη διαβάθμιση των ερωτήσεων, ελέγχει τη σύνταξη JavaScript και δημιουργεί αυτομάτως το πακέτο ZIP και το GitHub Release **v3.2**. Το GitHub Pages ενημερώνεται ανεξάρτητα από τη δημιουργία Release.

Τα κυριότερα αρχεία είναι `index.html`, `morphology_audit.csv`, `PHILOLOGICAL_AUDIT.md`, `RELEASE_NOTES.md`, `VERSION`, `tests/smoke.mjs`, `.github/workflows/pages.yml`.
